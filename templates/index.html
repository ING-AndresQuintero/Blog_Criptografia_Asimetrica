Fundamentos de la criptografía

Aprende los conceptos esenciales de los criptosistemas de clave pública.

01 | FUNDAMENTOS

¿Qué es la criptografía asimétrica?

La criptografía asimétrica es un sistema de protección de información que utiliza dos claves relacionadas: una clave pública y una clave privada.

La clave pública puede compartirse con otras personas, mientras que la clave privada debe permanecer protegida por su propietario.

Este mecanismo permite proteger comunicaciones, autenticar usuarios y verificar la integridad de la información mediante firmas digitales.

Referencia bibliográfica

Hernández, L. (2016). Criptografía de clave asimétrica. En La criptografía (pp. 93-134). CSIC.
02 | ALGORITMOS

Funcionamiento y algoritmos principales

El funcionamiento se basa en un par de claves matemáticamente relacionadas. Lo que se cifra con una clave puede recuperarse mediante la clave correspondiente, según el esquema utilizado.

Entre los algoritmos más conocidos se encuentran:

  • RSA: permite cifrado y firmas digitales.
  • Diffie-Hellman: permite acordar claves secretas.
  • ECC: utiliza curvas elípticas para ofrecer seguridad con claves más pequeñas.
  • ECDSA: permite generar y verificar firmas digitales.

Referencia bibliográfica

Hernández, L. (2016). La criptografía. CSIC.
03 | COMPARACIÓN

Ventajas y desventajas

La criptografía asimétrica facilita el intercambio seguro de información sin tener que compartir previamente una clave secreta.

Ventajas:

  • Permite el uso de firmas digitales.
  • Facilita el intercambio de claves.
  • Permite verificar autenticidad e integridad.

Desventajas:

  • Puede requerir más recursos computacionales.
  • Necesita proteger adecuadamente las claves privadas.
  • Requiere validar la autenticidad de las claves públicas.

A diferencia de AES, que utiliza una misma clave secreta para cifrar y descifrar, RSA utiliza un par de claves relacionadas.

Referencia bibliográfica

Maillo, J. (2017). Sistemas seguros de acceso y transmisión de datos. RA-MA.
04 | CASO PRÁCTICO

Implementación de RSA con Python

Para demostrar el funcionamiento de la criptografía asimétrica se propone desarrollar una aplicación utilizando Python y la biblioteca cryptography.

La aplicación permitirá generar un par de claves RSA, cifrar un mensaje con la clave pública y descifrarlo con la clave privada.

También permitirá crear una firma digital con la clave privada y verificarla con la clave pública.

Se utilizarán RSA-OAEP con SHA-256 para cifrado y RSA-PSS con SHA-256 para firmas digitales.

Referencia bibliográfica

Python Cryptographic Authority. (s. f.). Cryptography documentation.
05 | RECOMENDACIONES

Buenas prácticas de seguridad

La implementación de criptografía asimétrica debe acompañarse de buenas prácticas para evitar vulnerabilidades y proteger la información.

  • Proteger las claves privadas mediante controles de acceso y almacenamiento seguro.
  • Utilizar algoritmos y parámetros criptográficos actualizados.
  • Validar certificados y claves públicas.
  • Implementar copias de seguridad seguras.
  • Realizar pruebas de seguridad periódicas.
  • Evitar exponer información sensible en registros o interfaces públicas.

Como estrategia adicional, se recomienda utilizar cifrado híbrido: RSA para proteger una clave AES y AES para cifrar grandes cantidades de información.

Referencia bibliográfica

OWASP Foundation. (s. f.). Threat Modeling Process.
